# 项目截图说明文档

> **说明**：本文档描述了项目各页面的功能与展示能力，用于 GitHub README 截图和面试演示规划。

---

## 1. 登录页面

**截图位置**：`http://localhost:8000` 或 `http://localhost/login`

| 项目 | 说明 |
|------|------|
| **展示能力** | JWT 认证、用户注册/登录、表单验证 |
| **关键元素** | 用户名输入框、密码输入框、登录/注册切换、企业 Logo |
| **面试话术** | "前端使用 React + Tailwind 构建认证界面，后端通过 bcrypt 加密密码、JWT 签发 Token，实现了完整的用户认证闭环。" |

---

## 2. Dashboard 页面

**截图位置**：登录后首页 `/dashboard`

| 项目 | 说明 |
|------|------|
| **展示能力** | 系统概览、Agent 运行统计、服务器状态概览 |
| **关键元素** | CPU/内存/磁盘概览卡片、Agent 执行次数统计图、最近告警列表、系统运行时间 |
| **面试话术** | "Dashboard 聚合展示了系统核心指标，数据后端通过 Prometheus 采集和 SQLAlchemy 查询双通道获取。" |

---

## 3. AI Chat 页面

**截图位置**：`/chat`

| 项目 | 说明 |
|------|------|
| **展示能力** | AI Agent 对话、多轮对话管理、会话历史 |
| **关键元素** | 消息输入框、对话列表、上下文字段、消息气泡、Markdown 渲染 |
| **面试话术** | "Chat 页面是 Agent 的核心交互界面，用户通过自然语言输入运维指令，后端 LangGraph Agent 理解意图、调用工具、生成报告。" |

---

## 4. Agent Trace（执行轨迹）

**截图位置**：Chat 页面下方的 Trace 面板

| 项目 | 说明 |
|------|------|
| **展示能力** | WebSocket 实时推送、Agent 多步骤推理可视化 |
| **关键元素** | Step 执行步骤、工具调用状态（running/completed/failed）、中间结果展开 |
| **面试话术** | "Agent 的每一步执行都通过 WebSocket 实时推送到前端，用户可以直观看到 Agent 正在做什么、调用了哪些工具、结果如何。" |

---

## 5. 服务器管理页面

**截图位置**：`/servers`

| 项目 | 说明 |
|------|------|
| **展示能力** | 多服务器管理、SSH 远程连接、批量巡检 |
| **关键元素** | 服务器列表、状态指示灯（在线/离线）、连接配置、一键巡检按钮 |
| **面试话术** | "支持注册和管理多台远程服务器，Agent 可通过 SSH（paramiko）连接到任意服务器执行运维操作，包括健康检查、Docker 管理、日志查询。" |

---

## 6. Kubernetes 页面

**截图位置**：`/kubernetes`

| 项目 | 说明 |
|------|------|
| **展示能力** | K8s 集群管理、Pod 诊断、命名空间切换 |
| **关键元素** | Pod 列表（含状态颜色标识）、命名空间选择器、诊断输入框 |
| **面试话术** | "Kubernetes 页面提供了集群状态的图形化展示，Agent 可自动执行 kubectl 命令链完成故障诊断：get pods → describe → logs → 原因分析。" |

---

## 7. Monitoring 页面

**截图位置**：`/monitoring`

| 项目 | 说明 |
|------|------|
| **展示能力** | 实时系统指标、Prometheus 数据可视化 |
| **关键元素** | CPU 折线图、内存使用率、磁盘空间、HTTP 请求速率 |

## 8. Knowledge 页面（RAG 知识库）

**截图位置**：`/knowledge`

|------|------|
