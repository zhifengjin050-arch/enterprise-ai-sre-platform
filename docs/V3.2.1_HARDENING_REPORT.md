## 3. 修复问题

### JWT

- production：长度 &lt; 32 或含 `change-me` / `secret` / `password` / `test` → 启动失败，英文错误句固定。
- development：默认 `change-me-to-a-random-secret` 仍可运行。

### MCP 启动

- 系统环境 `ENABLE_MCP=false` 会盖掉 `.env`。
- `scripts/start_dev.ps1` 在本进程设置 `$env:ENABLE_MCP="true"` 后启动 uvicorn。
- `MCP_SERVER_CWD` 不存在时 **警告并继续启动**，不崩溃。

### 诊断接口 `GET /api/system/status`

仅返回：

`version`, `environment`, `database`（sqlite/postgresql）, `llm_provider`, `mcp_enabled`, `mcp_tools`, `redis_connected`, `otel_enabled`

禁止：API Key、JWT Secret、Database URL、Redis URL、MCP 路径。

鉴权：JWT 必填；development 已登录即可（Demo `webtest`）；production 需要用户角色或企业角色 `admin` / `devops`。

### Compose

`docker-compose.prod.yml` **未改**。风险写入 `docs/PRODUCTION_SETUP.md`：默认 Postgres/Redis/Grafana 密码、JWT 门禁、Redis healthcheck 未带 `-a`、Grafana `admin/admin`。

## 5. 使用方式

本地 Demo（推荐）：

```powershell
powershell -File scripts/start_dev.ps1
# 前端：cd frontend; npm run dev
# 登录：webtest / webtest123
```

诊断：

```bash
# 先 login 拿 token
GET http://127.0.0.1:8000/api/system/status
Authorization: Bearer <jwt>
```

生产：见 [PRODUCTION_SETUP.md](./PRODUCTION_SETUP.md)。`ENVIRONMENT=production` 时必须使用强 `JWT_SECRET`。

验收：

```bash
python -m pytest tests/test_v321_hardening.py tests/test_v31_hardening.py
python scripts/v3.2.1_hardening_acceptance.py
```
