**配置风险**

1. **High（运维）**：用户环境 `ENABLE_MCP=false` 覆盖 `.env` 的 `true`（python-dotenv 默认不 override）。当前 uvicorn 已用 `$env:ENABLE_MCP='true'` 重启并连上 17 工具；新开终端若不设，MCP 会再次关闭。
2. **Medium（dev）/ Critical（prod）**：JWT 长度 28、含 `change-me`；`ENVIRONMENT=development` 时启动门禁不拦。
3. **Medium**：Redis / RQ 未起，同步 Agent 仍可用。
4. **Low**：Grafana 未起走浅色占位；本机无 Docker / kubeconfig 时 MCP 返回结构化错误。

## 10. 上线门槛（若要从 Demo 到 Production）

1. 从用户/系统环境删除 `ENABLE_MCP=false`，或启动脚本强制 `$env:ENABLE_MCP='true'`。
2. `ENVIRONMENT=production` + 随机 `JWT_SECRET`（≥32 字节）。
3. `docker compose up -d` 拉起 Redis / Postgres / Prometheus / Grafana。
4. 生产库切 PostgreSQL；审批 token 勿仅存进程内存。
5. 浏览器人工过一遍 8 个页面的主题 / 中英 / console。
