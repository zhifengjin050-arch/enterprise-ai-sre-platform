## Architecture Status

### Agent Graph (LangGraph StateGraph)

```
START → agent (LLM 推理 + RAG/Memory 注入) → 条件分支
  ├─ tool_calls 待执行 → tools (执行工具) → agent (循环)
  └─ 无 tool_calls  → END (输出 final_report)
```

| 组件 | 状态 | 说明 |
|------|------|------|
| `graph.py` | ✅ | StateGraph 定义清晰，条件边正确 |
| `agent.py` (Agent Node) | ✅ | RAG 注入、Memory 注入、LLM Tool Calling、Trace 全链路 |
| `tools_node.py` (Tools Node) | ✅ | 工具执行、错误处理、Trace 更新 |
| `state.py` | ✅ | TypedDict 状态定义，Annotated + operator.add 消息累加 |
| `prompts.py` | ✅ | K8s / Docker / SSH / 知识库 / Auto Repair 全场景覆盖 |

## Known Issues

| ID | 问题 | 影响 | 建议 | 优先级 |
|----|------|------|------|--------|
| F1 | `datetime.utcnow()` 在 Python 3.12+ 触发 DeprecationWarning | 无运行时影响，Python 3.14 将移除 | 替换为 `datetime.now(UTC)` | P4 低 |
| F2 | FastAPI `on_event` 已弃用 | 无运行时影响 | 迁移为 `lifespan` 模式 | P4 低 |
| F3 | 部分旧测试因环境无法全量运行（需要 LLM API Key / Docker / K8s 集群） | 不影响核心功能验证 | 运行 `test_v33_knowledge_hub.py` 覆盖 v3.3 功能 | P5 低 |

### 非阻塞建议

| 建议 | 说明 |
|------|------|
| 全局 Exception Handler | 目前依赖 try/except 分散处理，建议添加 `@app.exception_handler` 统一响应格式 |
| 数据库迁移 Base 统一 | 确认 `app/knowledge/models.py` 与 `app/database/models.py` 共用同一 Base |
