## 2. 技术亮点

### 亮点 1：LangGraph 状态图驱动的 Agent 编排

```python
START → agent (LLM + RAG + Memory) → 条件分支
  ├─ tool_calls 待执行 → tools → agent (循环)
  └─ 无工具调用 → END → 输出 final_report
```

- 简洁稳定的两节点循环设计
- 条件边 `should_continue` 灵活控制工具调用次数
- 每次推理前自动注入 RAG 上下文 + Memory 上下文

### 亮点 2：MCP 协议实现工具与 Agent 解耦

- 工具作为独立 Server 进程运行，Agent 通过 stdio 通信
- `list_tools()` 运行时动态发现，新增工具无需改代码
- MCP 工具与内置工具自动合并，同名 MCP 优先
- 进程隔离保证 MCP Server 崩溃不影响 Agent

### 亮点 3：RAG + 企业知识 Hub 实现知识即服务

- 统一文档提供者合并手动文档 + Hub 文档
- Organization 级别多租户隔离
- 飞书连接器定时自动同步 Wiki 文档
- Fernet 加密存储外部凭据

### 亮点 4：全链路可观测性

- Agent Trace：每一步工具调用的输入/输出/耗时全记录
- SSE 实时流式输出：Agent 推理过程前端实时展示
- Prometheus 指标：HTTP / LLM / Agent / MCP 全覆盖
- OpenTelemetry 分布式追踪

### 亮点 5：企业级安全设计

- JWT 认证 + bcrypt 密码哈希
- RBAC 三角色（Admin/DevOps/Viewer）+ Organization 多租户
- 生产环境启动门禁（弱密钥拒绝启动）
- SecretFilter 日志脱敏
- Fernet 凭据加密
- 危险操作需人工审批
