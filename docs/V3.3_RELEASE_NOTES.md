# Release Notes — v3.3.0 Enterprise Knowledge Hub

> **发布日期**: 2026-08-18  
> **版本**: `v3.3.0`  
> **代号**: Enterprise Knowledge Hub  
> **兼容性**: 向后兼容 v3.2.x API，数据库迁移可回滚

---

## 🎯 版本概述

v3.3.0 是 **Enterprise Knowledge Hub** 版本，在前序版本（AI Agent + MCP + RAG + Auto Repair + SRE Console）基础上，新增了**企业级知识管理**能力：

- 多租户知识库（Organization 级别数据隔离）
- 飞书知识库连接器（定时同步 Wiki 文档）
- 外部知识源管理（CRUD + 凭据加密）
- 统一文档提供者（Agent 知识搜索同时覆盖手动文档和 Hub 文档）
- Demo 数据包（开箱即用体验）

## ✨ 新功能

### 1. 企业知识 Hub（Knowledge Hub）

**新增模块**: `app/knowledge/`

| 组件 | 说明 |
|------|------|
| `provider.py` | 统一文档提供者，合并手动文档 + Hub 文档 |
| `pipeline.py` | 知识同步 Pipeline：验证 → 列出 → 拉取 → 解析 → 写入 |

| `models.py` | KnowledgeDocument、KnowledgeChunk、KnowledgeSource、SyncTask、SyncLog |

**新增 API** (`/api/knowledge-hub/`):

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/knowledge-hub/sources` | GET/POST | 知识源列表 / 创建 |

| `/api/knowledge-hub/documents` | GET | Hub 文档列表（已分页） |
| `/api/knowledge-hub/sync` | POST | 触发同步任务 |
| `/api/knowledge-hub/sync/tasks` | GET | 同步任务历史 |

## 🔧 改进

### 架构改进

- **RAG 引擎增强**: 支持多租户文档隔离（organization_id + user_id 过滤）
- **文档提供者统一**: 手动文档（`documents` 表）与 Hub 文档（`knowledge_documents` 表）通过 UnifiedDocumentProvider 合并
- **凭据安全存储**: 外部知识源的 API Token / Secret 使用 Fernet 加密后存入数据库
- **Embedding 降级控制**: Hub 文档在 Embedding API 不可用时跳过，不阻塞同步流程

### 安全性改进

- 外部连接凭据加密存储（`cryptography.fernet`）
- 知识源按 Organization 隔离，跨组织不可见
- Hub 文档 RBAC：Viewer 只读、Admin 完全管理

### 前端改进

- 新增 Knowledge Hub 页面（标签页：文档 / 知识源 / 搜索）
- 版本号更新至 v3.3.0

## 🐛 Bug 修复

| 问题 | 修复 |
|------|------|
| datetime.utcnow() 弃用警告 | 替换为 `datetime.now(UTC)` |
| RAG 向量搜索缺少 SASession 导入 | 添加 `from sqlalchemy.orm import Session as SASession` |
| SQLite UNIQUE 约束冲突 | 测试用例使用 UUID 生成唯一 slug |

## 📦 安装与升级

### 全新安装

```bash
git clone https://github.com/your-org/enterprise-ai-sre-platform.git
cd enterprise-ai-sre-platform
cp .env.example .env
pip install -r requirements.txt
alembic upgrade head
python run.py
```

### 从 v3.2.x 升级

```bash
# 1. 拉取代码
git pull

# 2. 安装新增依赖
pip install -r requirements.txt

# 3. 执行数据库迁移（新增 5 张知识库表）
alembic upgrade head

# 4. 重启服务
python run.py
```
