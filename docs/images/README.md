# 运行截图

## 截图列表

| 截图 | 说明 |
|------|------|
| dashboard.png | 系统仪表盘首页 |
| chat.png | AI 对话页面 |
| chat-streaming.png | 流式输出实时展示 |
| trace.png | Agent Trace 执行轨迹 |

## 生成截图说明

请在实际运行项目后，使用截图工具捕获以下页面：

1. **dashboard.png**: 访问 http://localhost:8000/dashboard
2. **chat.png**: 在聊天界面发送一条消息，截图对话过程
3. **chat-streaming.png**: 使用流式接口，截图实时输出过程
4. **trace.png**: 访问 /trace 页面（前端新增），截图执行轨迹
5. **mcp-tools.png**: 截图 MCP 工具列表页面
6. **rag-search.png**: 截图知识库检索结果
7. **vision-analysis.png**: 截图视觉模型分析结果
8. **server-health.png**: 截图服务器健康状态页面
